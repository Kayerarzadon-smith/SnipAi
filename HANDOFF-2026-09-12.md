## What SnipAi is

Local-only macOS app, no accounts, no cloud. Next.js 14 standalone server +
a thin Swift/WKWebView wrapper (`native/`) driving a Python/ffmpeg/
faster-whisper pipeline (`ugc-edit-system/`). Kayer records TikTok-style
supplement videos on his iPhone across multiple takes, and the app is
supposed to turn raw clips into one tight, postable cut with minimal
manual editing.

## How to actually run things

```bash
./scripts/test          # types, unit tests, guards -- run before every push
./scripts/qa --fast     # cheap pre-commit checks
./scripts/qa --full     # full gate, what bundle-app requires
./scripts/bundle-app    # rebuilds SnipAi.app -- see warning above
./scripts/docket        # prints what's currently open
python3 scripts/guard-ledger.py   # checks ledger rows agree with test results
```

Regression tests live in `tests/regressions/` and are *written to fail*
until their bug is fixed — they don't gate the normal test run, but
`guard-ledger.py` fails if a regression test goes green while its ledger
row still says `open` (or vice versa — that mismatch has bitten this
project multiple times tonight; read `T20`'s row for the whole story).
